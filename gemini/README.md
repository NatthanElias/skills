# Antigravity skills

Personal Agent Skills for Google Antigravity. Each skill keeps its instructions
and supporting files together in its own folder.

## Install

Copy a skill directory into Antigravity's global skills directory:

```bash
mkdir -p ~/.gemini/config/skills
cp -a gemini/explain ~/.gemini/config/skills/
```

Antigravity also discovers project skills from `.agents/skills/`. See the
[skill format guide](https://antigravity.google/docs/skills).
